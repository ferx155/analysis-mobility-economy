# Mobility Economy Analysis

Este repositorio contiene el análisis de mobilidad urbana contra la economía de diferentes ciudades con el objetivo de dar claridad a una compañía financiera sobre dónde es más conviente invertir en infraestructura para sus sucursales.

El dataset 'mobility_economy' incluye datos sobre tráfico por ciudad así como la economía de cada una de ellas.

## Contenido del repositorio

- '/datasets/tomtom_traffic.csv'
Notebook principal con limpieza, join, análisis, visualizaciones y conclusiones.

- Identificar llaves para combinar datasets
- Analizar patrones y comportamientos
